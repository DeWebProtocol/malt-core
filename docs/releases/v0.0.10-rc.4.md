# MALT Core v0.0.10-rc.4

This source candidate completes the separation of comparison-only evaluation
algorithms from the application-neutral Core SDK and refreshes the security
policy for the current contracts.

## Changes

- The experimental compact binary SHA256 trie, its independent formats, tests
  and documentation now live in `malt-evaluation/internal/baselines/hashtrie`.
  Core has no forwarding package. An architecture test prevents that baseline
  from returning to Core.
- The security policy now describes caller-selected complete Roots, strict
  verification, exact commitment profiles, the Core-owned protocol boundary,
  and persistence and application responsibilities outside the SDK.

## Compatibility and limits

Relative to `v0.0.10-rc.3`, native Go SDK APIs, authentication algorithms, Root
encoding, proof and schema identifiers, and
`conformance/authentication-v2.json` are unchanged. The hash-trie package was
added and removed on intervening development commits; it was never part of
rc.3. Consumers of those development commits must move to the evaluator-owned
baseline rather than importing `auth/experimental/hashtrie` from Core.

Root V remains 0. This experimental source release does not declare production
readiness. Candidate Roots and execution receipts are not portable
state-transition proofs, remote availability guarantees or trusted-root
promotion. The hash baseline's binary branching does not establish optimal
proof size across branching factors.

Core publishes Go source, protocol schemas and portable conformance data.
`malt-ts` independently binds the exact published Core tag, commit and Go
module checksums, then builds its browser WASM assets. Gateway, local runtime
and evaluator adoption is recorded by their own dependency locks; historical
evaluation pins and results retain their original identities.

## Release validation

The GitHub prerelease records the exact tagged commit and completed validation:
full Go tests, 32-bit commitment tests, vet, package builds, public examples,
and an external module importing the intended public SDK packages. Release
preparation uses `MALT_RELEASE_BASE=v0.0.10-rc.3` and checks the complete diff
against that source tag.
