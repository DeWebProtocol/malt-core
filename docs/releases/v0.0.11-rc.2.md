# MALT Core v0.0.11-rc.2

This source prerelease adds retained-writer read capabilities and enables
multicore KZG commitments and openings within the current Go scheduler budget.

## Changes since v0.0.11-rc.1

- `authentication.Writer.Lookup`, `Nodes`, `Len` and `StateCharge` expose local
  retained-state reads and conservative accounting without exporting the entire
  state. Each `Nodes` reader is traversal-local; returned cells are owned copies.
  Lookup rejects original-label coordinate collisions. These local operations
  do not produce portable membership or state-transition evidence.
- KZG MSM task sizing follows `runtime.GOMAXPROCS(0)` for each operation and is
  capped at 1024, gnark's explicit task-count limit. It no longer forces one
  task, and it does not use gnark's host-CPU-based automatic default. This is
  task sizing within one operation, not admission control for concurrent requests.
- Update `golang.org/x/sync` from v0.23.0 to v0.24.0 and `golang.org/x/sys`
  from v0.48.0 to v0.49.0.

## Compatibility and limits

Existing public SDK APIs, Root V=0, Prefix layout 4, Positional layout 3,
commitment and proof encodings, protocol schemas and the portable conformance
corpus are unchanged from v0.0.11-rc.1. KZG commitments and openings must remain
byte-identical across scheduler budgets; task count is not cryptographic input.
Performance depends on the host, available CPU budget and request concurrency;
this release does not promise a fixed speedup.

This experimental release does not declare production readiness. Candidate
Roots, graph deltas and materialization receipts do not establish authenticated
transitions, publication, freshness or client trust.

Core publishes Go source, protocol schemas and portable conformance data.
`malt-ts` adopts the exact published tag, commit and module checksums before
building browser WASM assets. Downstream dependency updates are recorded in
their own repositories. Historical evaluation pins and results retain their
original identities.

## Release validation

The GitHub prerelease records the final tag target and completed validation.
Preparation uses `MALT_RELEASE_BASE=v0.0.11-rc.1` and covers full Go tests,
32-bit commitment tests, vet/build, public examples, cross-platform builds,
deterministic conformance regeneration and an external public-API consumer.
The KZG regression tests cover task sizing, unchanged commitment/proof bytes
and concurrent calls on a shared immutable prepared opening, including under
the race detector.
