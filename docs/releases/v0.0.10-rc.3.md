# MALT Core v0.0.10-rc.3

This candidate adds an optional Go Object API for constructing state through
ordinary references. The README now walks through Commit, Prove, Update and
Verify with a runnable Map and Immutable example.

## Changes

- `sdk/object.Object` represents one application vertex. Raw-byte `Immutable`
  leaves return content CIDs; Prefix `Map`, Positional `List`, and structs using
  `Base.CommitTagged` return MALT Roots. Map and List work with either installed
  IPA or KZG profiles.
- Recursive Commit visits children first, detects cycles, and commits shared
  child pointers once per traversal. It rereads current references without
  dirty tracking and reuses `Writer.Update` for unchanged configurations.
- Objects retain the exact graph versions used by their successful Commits.
  All managed snapshots advance only after the enclosing Commit succeeds;
  failure or cancellation preserves the prior snapshots and delta for retries.
- `Delta(ctx)` compares the enclosing graph's last two committed versions,
  including children committed independently in between. It collects exact
  label changes, child-first ArcSet candidates on demand, newly referenced
  local content bytes, and external CID dependencies, deduplicated by CID.
- `authentication.Writer.State(ctx)` copies retained labels, targets and
  configuration without exporting authentication vectors.
- Six runnable examples cover the basic Object flow, composed Objects, direct
  traversal, byte ranges, serialized queries and retained writers. The former
  `examples/binding` walkthrough now lives in `examples/query`.

## Compatibility and limits

Relative to `v0.0.10-rc.2`, the Go SDK additions preserve existing APIs and
authentication behavior. Root encoding, exact commitment profiles, proof and
schema identifiers, and `conformance/authentication-v2.json` are unchanged.
Root V remains 0; this release does not declare production readiness.

The new containers use the current authentication API and do not restore the
retired semantic Map/List facade. Prefix payloads use an ordinary SDK-level
reserved label. This first List implementation has no independent payload and
returns `cid.Undef` from `Payload()`.

Commit confirms local SDK snapshots and performs no persistent storage writes.
Delta contains write candidates relative to the previous local graph, not
remote availability claims or a portable state-transition proof. Keep each
delta until its writes are handled; the next successful Commit advances the
baseline. Removed references do not request physical content deletion.
Objects are not safe for concurrent mutation or Commit.

Existing Gateway, runtime, TypeScript and evaluator dependencies can remain on
rc.2 until they adopt the new APIs. Core publishes Go source and portable
protocol/conformance data. WASM builds and distribution remain in malt-ts,
which adopts an exact published Core release separately.

The GitHub prerelease records the exact final source commit and completed
validation. See the [Object guide](../guides/objects.md) and
[README walkthrough](../../README.md#quick-start) for usage.
