# MALT Core v0.0.10-rc.1

This candidate separates application labels, coordinate derivation and
coordinate-only authentication. `derivation.Derive` supports Direct (ID 3) and
SHA256 (ID 4). `auth/coordinate.Coordinate` contains a 32-byte Prefix key or a
uint64 Positional index; Direct index labels use exactly eight big-endian bytes.

The label-aware engine moves to `engine`. `auth/input`, its tagged Value,
mutable rule registry, system payload selector and UnixFS name rule are removed.
Shared SDK calls, traversal and candidates use opaque label bytes. Persistent
relation adapters retain those original label–target bindings; coordinates are
reconstructed using the Root's public derivation profile.

This is a breaking experimental release. Candidates use `malt.authentication/2`,
queries/results `/3`, and delta/batch/receipt profiles `/1`. The portable corpus
is `conformance/authentication-v2.json`. Retired profiles 0–2 are not reassigned
or executed by the current engine. Root V stays 0. Reconstruct old experimental
relation state and dependent parents; retain unchanged CAS payloads. Applications
own payload labels, reserved names, UnixFS validation and path organization.

Core publishes source and conformance data. The TypeScript/WASM distribution
adopts this exact published release in its own lock and performs native/WASM
parity and reproducible asset checks before downstream distribution.
